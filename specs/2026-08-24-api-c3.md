# Target C3: one API (not as-built)

**Status:** Target workshop picture. C4 **level 3 (component)** of the **one API** in [integrated system](2026-08-24-integrated-system.md). **Not** the prototype FastAPI in [docs/c4/component.md](../docs/c4/component.md).

**Swire is not a component of this API.** It is an external proctor suite that exposes its own HTTP API. Live stays inside this process so maps share roomsdb.

## API internals

Four folders in **one process**. The gate is the Person cookie (or none, for live). There is no room cookie here.

```mermaid
%%{init: {"theme": "neutral"}}%%
flowchart TB
  subgraph api [Container: one API]
    googleAuth["Component: Google OAuth"]
    personSess["Component: Person cookie"]
    gate["Component: route auth"]
    subgraph roomsdbFolder ["/api/v1/roomsdb"]
      roomsdbPublic["Component: public GET rooms/maps"]
      roomsdbStaff["Component: staff writes"]
    end
    subgraph opsFolder ["/api/v1/ops"]
      opsDrafts["Component: drafts / planner"]
      opsDay["Component: day plan + HQ"]
      opsVolAdmin["Component: volunteer admin"]
    end
    subgraph volFolder ["/api/v1/volunteers"]
      volMe["Component: me apply / assignment"]
      volInternal["Component: volunteer internals"]
    end
    subgraph liveFolder ["/api/v1/live"]
      liveSnap["Component: public snapshot"]
      liveMaps["Component: maps"]
      liveSub["Component: email subscribe"]
    end
  end
  swire["External: Swire API"]
  google["External: Google Identity"]
  postgres["External: PostgreSQL"]
  mail["External: email"]
  googleAuth --> google
  googleAuth --> personSess
  personSess --> gate
  gate --> roomsdbPublic
  gate --> roomsdbStaff
  gate --> opsDrafts
  gate --> opsDay
  gate --> opsVolAdmin
  gate --> volMe
  gate --> volInternal
  gate --> liveSnap
  gate --> liveMaps
  gate --> liveSub
  opsDay -->|"pause / add time / clarifications; fail soft"| swire
  swire -->|"optional public GET rooms"| roomsdbPublic
  roomsdbPublic --> postgres
  roomsdbStaff --> postgres
  opsDrafts --> postgres
  opsDay --> postgres
  opsVolAdmin --> postgres
  volMe --> postgres
  volInternal --> postgres
  liveSnap --> postgres
  liveMaps --> postgres
  liveSub --> postgres
  liveSub --> mail
```

Staff volunteer routes live under **`/ops/` or `/volunteers/` once**, not both.

Day-of and Swire never write rooms: only `roomsdbStaff` updates buildings/floors/rooms.
