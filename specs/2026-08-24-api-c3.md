# Target C3: one API (not as-built)

**Status:** Target workshop picture. C4 **level 3 (component)** of the **one API** in [integrated system](2026-08-24-integrated-system.md).

**Swire is not a component of this API.** Swire admins are the only writers. Proctors cannot modify it. The exposed API is read-only; this platform polls it. **Maps are a folder of this API**, read by both HQ and live.

## API internals

Five folders in **one process**. The gate is the Person cookie (or none, for public live and public map geometry). There is no room cookie here. Maps are not inside `/live/`. Roomsdb has no unauthenticated GET. If the live or Swire builders later want room labels without a roomsdb login, add one small GET then. It is not a component on this picture.

Staff volunteer writes live under **`/volunteers/`**, used from `volunteers.berkeley.mt/admin`. The HQ page does not call them.

Day-of and Swire never write rooms: only `roomsdbStaff` updates buildings/floors/rooms.
